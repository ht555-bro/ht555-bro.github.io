Privacy Policy

Effective date: 2026-11-25

About this tool

rclone-drive is a personal tool operated by a single individual (the "operator") for private, non-commercial use. It is not a public service and has no registered users other than the operator.

Data accessed

The tool uses the Google Drive API (scope: https://www.googleapis.com/auth/drive) to upload, list, and download files inside a single designated folder of the operator's own Google Drive account. The files are the operator's own backups (application data and generated images from the operator's home server).

How data is handled

  • Backup data is encrypted on the operator's own machine before it is uploaded. File names and file contents stored in Google Drive are encrypted.
  • No data is collected from, or shared with, any third party.
  • No data is sold, used for advertising, or used to train models.
  • Access credentials (OAuth tokens) are stored only on the operator's own infrastructure and are used solely to operate the backups described above.

Data retention and deletion

Backup files remain in the operator's Google Drive account until the operator deletes them. Deleting the files from Google Drive removes them permanently, subject to Google Drive's own trash and retention behavior.
