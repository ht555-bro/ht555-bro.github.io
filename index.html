rclone-drive

rclone-drive is a personal, single-user backup tool. It uses rclone with the Google Drive API to store encrypted backups of the owner's own files (application data and generated images from a self-hosted home server) in a designated folder of the owner's own Google Drive account.

The tool is not distributed to the public and has no other users. All backup data is encrypted on the owner's machine before upload, so file names and contents are not readable from Google Drive alone.
